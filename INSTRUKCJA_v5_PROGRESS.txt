1. FIREBASE STORAGE
Firebase Console -> Build -> Storage -> Get started.

Jeśli Firebase wymaga planu Blaze, Cloud Storage nie uruchomi się bez jego aktywacji.
Pomiary działają niezależnie od Storage.

2. STORAGE RULES
Po uruchomieniu Storage:
Storage -> Rules
Otwórz storage-rules-FINAL.txt.

W obu miejscach w paczce:
WKLEJ_TUTAJ_SWOJ_UID
zamień na ten sam UID administratora, którego użyłeś do Realtime Database.

Wklej reguły w Storage -> Rules -> Publish.

Te reguły:
- pozwalają publicznie oglądać zdjęcia
- upload/delete tylko z Twojego UID
- przyjmują tylko pliki typu image/*
- limit uploadu: 8 MB

3. REALTIME DATABASE
Jeśli masz już zabezpieczone reguły z v4, nie musisz ich zmieniać.
firebase-rules-FINAL.json jest dołączony dla pewności.
