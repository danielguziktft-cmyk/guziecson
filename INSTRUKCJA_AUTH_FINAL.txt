GUZIECSON 90 — FINALNE ZABEZPIECZENIE

1. FIREBASE AUTHENTICATION
Firebase Console -> Build -> Authentication -> Get started.
Zakładka Sign-in method -> Email/Password -> Enable -> Save.

2. UTWÓRZ TYLKO SWOJE KONTO
Authentication -> Users -> Add user.
Podaj swój e-mail i mocne hasło.
Nie dodawaj kont dla widzów.

3. SKOPIUJ UID
Po utworzeniu użytkownika w tabeli Users zobaczysz kolumnę User UID.
Skopiuj UID.

4. REGUŁY REALTIME DATABASE
Otwórz firebase-rules-FINAL.json.
Zamień:
WKLEJ_TUTAJ_SWOJ_UID
na swój prawdziwy UID.

Firebase Console -> Realtime Database -> Rules.
Wklej wynik i kliknij Publish.

Efekt:
- każdy może READ, więc index.html, overlay.html i end.html działają publicznie;
- WRITE ma tylko dokładnie konto z Twoim UID.

5. GITHUB

W szczególności:

config.js
control.html
index.html
overlay.html
end.html
start.html
style.css
